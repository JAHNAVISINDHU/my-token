# MyToken (MTK)

## Overview
MyToken is a simple ERC-20 token built for learning purposes.

## Token Details
- **Name:** MyToken
- **Symbol:** MTK
- **Decimals:** 18
- **Total Supply:** 1,000,000 MTK

## Features
- ERC-20 standard
- transfer, approve, transferFrom
- Event emission
- Balance and allowance tracking

## How to Deploy
1. Open Remix
2. Create MyToken.sol
3. Compile using 0.8.x
4. Deploy with:
   1000000000000000000000000

## How to Use

### Check balance
balanceOf(address)

### Transfer
transfer(address, uint256)

### Approve
approve(address, uint256)

### Transfer on behalf
transferFrom(address, address, uint256)
